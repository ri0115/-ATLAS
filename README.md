# 診療報酬 ATLAS — 公開用Webサイト

**Medical Reimbursement Intelligence / 2024**

第11回NDBオープンデータを基に、全国・都道府県・二次医療圏における診療報酬構造の分析を目指すプロジェクトです。このリポジトリは**公開画面専用**です。

## UIデザイン

元HTML `REIMBURSEMENT_ATLAS_v2_0_MODALITY_RELATED_FEES.html` のCSS、ヘッダー、4タブ、地域プロファイルの2カラム構造を復元。公開版はデータなしのUIプレビューで、数値は認証付き詳細サイトから取得する構成を維持。旧HTML内の埋め込みデータとデータ処理スクリプトは公開リポジトリへ移していない。

## データ保護方針

**HTMLにデータを組み込まないだけでは、保護にはなりません。** ブラウザがダウンロードできるCSV/JSONは開発者ツールや直接URLから取得できます。フロントエンドのパスワード、JavaScriptの暗号化、URLの推測しにくさ、CORSだけで秘密データを保護しないでください。

| 項目 | 公開サイト | 保護されたデータ領域 |
|---|---|---|
| 表示コード・スタイル・画面仕様 | ✅ | — |
| 年度、収録コード数、医療圏数などの概要 | ✅ | — |
| 個別コードごとの点数・算定要件の照合記録 | しない | ✅ |
| 医療圏×コード×算定回数・参考換算額 | しない | ✅ |
| 年度内点数改定履歴・監査の生データ | しない | ✅ |
| 全件CSV/SQLite、生成済み大容量HTML | しない | ✅ |

### 今後の拡張構成（構想）

```text
[ブラウザ]
  └─ GitHub Pages：公開UI（HTML/CSS/JavaScript／概要情報）
         │ HTTPS + 認証済みリクエスト（将来）
         ▼
[API/BFF：別ホストのサーバー実行環境]
  ├─ ログイン・セッション認証と権限確認
  ├─ 利用者ごとの閲覧可能範囲判定
  ├─ クエリ件数・検索範囲制限とレート制御
  ├─ 過大な再抽出を避ける最小集計結果のみ返却
  └─ 非公開DB／非公開ストレージ：全9,275コード・330医療圏の詳細
```

認証・認可を**API側で行う**こと。認証後に返すデータは閲覧者から取得可能であり、完全なコピー防止はできません。閲覧権限、返す粒度、CSV出力上限、表示する元データの二次利用条件などを設計します。詳細レスポンスには`Cache-Control: private, no-store`を付与し、非公開ストレージの資格情報をブラウザへ渡しません。

## 計算上の注意

参考換算額は公開算定回数に点数を掛けて10円換算した分析指標であり、実際の医療機関収益や利益ではありません。NDBの秘匿、DPCの包括、年度内点数改定、地域区分の変更等により誤差が生じ得ます。

**この公開リポジトリはデータ再配布を目的としていません。** サイトに表示できる内容は今後、公開粒度と一次資料の条件を踏まえて段階的に増やします。

## 地域特化 TOP100（2024年度）

地域プロファイルの「9桁コードの地域特化」から、47都道府県・330二次医療圏を選択可能。Vercel上に既存の全コード原票を再利用し、`GET /v1/specialization` で地域・公費・原票粒度・順位基準・A〜O区分・最低参考換算額を指定して最大100件を取得。集計値は地域全区分合計と全国同一粒度の合計を照合し、不一致の場合は応答しない。超過額は地域総額×全国当該コード構成比に対する差額。LQは構成比同士の比、人口当たり全国平均比は100基準。旧秋田8圏域は現行3圏域へ合算。行クリックで個別コード詳細へ同一地域・同一公費条件を引継ぐ。秘匿・未設定点数を補完しない。公開GitHubにはデータを含まない。


## ENTER表紙・A〜O構成比・技術別詳細（v2.0復元）

- 表紙のENTER（Enterキー対応）で現在のVercel認証ブリッジを開始し、成功時にATLAS画面を表示。中継終了時はデータを消去して表紙に戻る。認証ウィンドウは分析中に開いておく必要がある。
- A〜Oの16区分は固定パレットで色を割り当て、全区分の構成比を100%積み上げで表示。凡例・LQ表と連動、クリックでコード検索へ。
- `/v1/modality` は元v2.0の51本体関連コード＋59関連コード（110コード・35分類）を同一原票から集計。CT列数5分類、MRI磁場3分類、US検査20分類、専用加算3分類、共通・独立・帰属保留4分類。対象地域と比較地域は同一原票粒度／公費条件。E203等は技術別に配賦しない。全データはVercel保護内に保持。


## 認証セッション方式（2026-11-18）

ENTERから既存の保護済みVercelで認証し、固定されたGitHub Pagesの戻り先へ同じタブで戻る。セッションは60分、有効期限・署名とランダムなproofのSHA-256照合を行う。ブラウザでは認証トークンをメモリだけに保持し、ログイン往復用の一時情報のみsessionStorageを利用して戻り時に削除。公開APIゲートウェイは署名・期限・proofを検証し、Trusted Sourcesのサーバー側OIDCで既存の非公開APIに転送する。秘密鍵は既存Vercelのみ、ゲートウェイは公開検証鍵のみ。生データは移動しない。ゲートウェイからの認証発行への転送は禁止。本番ゲートウェイ→非公開APIの通信を実測し、47都道府県・16区分・D215の20コード・35技術分類・地域特化100件を取得できることを確認。未認証、不正proof、許可外パス・オリジンは拒否、CORSプリフライトも確認。実ユーザーによる対話的ログインと画面確認は別途必要。ブラウザを再読み込みする場合はENTERから再接続する。


## 全診療報酬の地域比較・市場マップ

大分類＝A〜O（K手術と輸血料は別）、中分類＝NDBマスターに照合済みの点数表分類番号、小分類＝9桁コード。中・小分類には番号・名称で候補を絞る検索欄も用意。分類番号未照合のコードも選択可能。CT/MRI/USの本体＋専用加算も別途選べる。比較APIは全47都道府県・330二次医療圏を同じ原票条件で返す。金額・公開算定回数・人口当たり・全国平均比・LQ（全区分構成比）を切替。地図にはCC0の [lalamalink/japan-map-svg](https://github.com/lalamalink/japan-map-svg) を使用（概略図、境界精度なし）。二次医療圏は都道府県でグループ化したタイル表示であり、地理的境界ポリゴンは別途整備が必要。APIは既存のセッション・Trusted Sourcesを維持し、数値はGitHubに保存しない。
