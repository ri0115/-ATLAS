# 診療報酬 ATLAS — 公開用Webサイト

**Medical Reimbursement Intelligence / 2024**

第11回NDBオープンデータを基に、全国・都道府県・二次医療圏における診療報酬構造の分析を目指すプロジェクトです。このリポジトリは**公開画面専用**です。

## サイト

GitHub Pages: https://ri0115.github.io/-ATLAS/

※ GitHubの **Settings → Pages → Build and deployment → Source: GitHub Actions** が設定され、デプロイが成功している必要があります。サイトはそれまでは公開URLで開けません。

- `docs/index.html`：4タブ画面。診療行為データや集計金額は埋め込んでいません
- `docs/assets/style.css`：配色・レイアウト・レスポンシブデザイン
- `docs/assets/app.js`：UI操作。認証データAPIは未接続
- `docs/assets/public-manifest.json`：**公開を許可した件数などの概要のみ**
- `.github/workflows/pages.yml`：GitHub Pagesへ静的サイトをデプロイ
- `scripts/check_public.py`：公開対象外ファイルや巨大アセットを検出

## データ保護方針

**HTMLにデータを組み込まないだけでは、保護にはなりません。** ブラウザがダウンロードできるCSV/JSONは開発者ツールや直接URLから取得できます。フロントエンドのパスワード、JavaScriptの暗号化、URLの推測しにくさ、CORSだけで秘密データを保護しないでください。

| 項目 | 公開サイト | 保護されたデータ領域 |
|---|---|---|
| 表示コード・スタイル・画面仕様 | ✅ | — |
| 年度、収録コード数、医療圏数などの概要 | ✅ | — |
| 個別コードごとの点数・算定要件の照合記録 | しない | ✅ |
| 医療圏×コード×算定回数・参考換算額 | しない | ✅ |
| 年度内点数改定履歴・監査の生データ | しない | ✅ |
| 全件CSV/SQLite、生成済み大容量HTML | しない | ✅ |

現段階で認証APIは未実装です。表示画面は**公開プレビュー**であり、ログインできると誤認させるボタンを配置していません。

### 認証付き分析の初回実装案

公開プレビューは GitHub Pages で提供します。詳細分析は公開プレビューから別の認証付きサイトに遷移し、そのサイトと同じオリジンの API を呼び出します。認証済みセッションで使う Cookie に `HttpOnly`、`Secure`、`SameSite=Lax` を設定し、API はセッションと各利用者に付与された都道府県の閲覧権限を照合します。API から非公開ストレージへは読み取り専用の資格情報を使います。

#### 医療圏一覧と年次集計

| API | 入力 | 返す項目 |
|---|---|---|
| `GET /v1/areas?pref=13` | 都道府県コードを1件指定 | `areas` に医療圏コードと表示名。配列は最大100件 |
| `GET /v1/areas/{code}/summary` | 医療圏コードを1件指定。年度は2024年度に固定 | 年度、医療圏コード、データ版、集計区分、区分別の参考換算額と集計状態 |

医療圏コードはマスターの文字列を使用し、先頭ゼロを保持します。初回は年度・性年齢・月・公費の任意の絞り込みを設けず、コード別検索と一括出力は後続の検討対象とします。

区分別集計は `reference_amount_yen`（整数円または `null`）と `status` を返します。状態は `available`（表示可能）、`partial`（公表値から計算した部分集計）、`suppressed`（秘匿）、`unavailable`（集計不可）とします。秘匿・集計不可は金額を `null` にし、実測のゼロと区別します。部分集計の表示は、他の返却値との差分から秘匿値を推定できない場合に限ります。レスポンスには参照元のデータ版と集計区分を含め、画面には「参考換算額」と表示します。実データを接続する際に、DPC包括、公費の扱い、点数改定の処理を元データの算定条件と照合します。

#### 実装時の受け入れ条件

- 未ログインは `401`、閲覧権限外または未登録の医療圏は同じ `404`、不正なパラメータは `400` を返す。権限の照合はデータ取得より前に行う。
- 各詳細 API で `Cache-Control: private, no-store` を返す。利用者単位のレート制限を設け、超過時は `429` と `Retry-After` を返す。
- 返却項目はサーバー側の許可リストで選択する。実データ接続前に架空データでログイン状態、地域ごとの権限、返却項目、秘匿・欠損・ゼロの表示を確認する。

進捗と実装範囲は [Issue #1](https://github.com/ri0115/-ATLAS/issues/1) を参照してください。

## 公開前の確認

```bash
python3 scripts/check_public.py
node --check docs/assets/app.js
```

**注意:** `.gitignore` やCIでの検査は補助策です。公開リポジトリに秘密ファイルを一度コミットすると、CIが失敗してもGit履歴から取得できる可能性があります。生データをこの公開リポジトリにコピーしないことを原則にしてください。

## 計算上の注意

参考換算額は公開算定回数に点数を掛けて10円換算した分析指標であり、実際の医療機関収益や利益ではありません。NDBの秘匿、DPCの包括、年度内点数改定、地域区分の変更等により誤差が生じ得ます。

**この公開リポジトリはデータ再配布を目的としていません。** サイトに表示できる内容は今後、公開粒度と一次資料の条件を踏まえて段階的に増やします。
