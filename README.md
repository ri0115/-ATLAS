# 診療報酬 ATLAS — 公開用Webサイト

**Medical Reimbursement Intelligence / 2024**

第11回NDBオープンデータを基に、全国・都道府県・二次医療圏における診療報酬構造の分析を目指すプロジェクトです。このリポジトリは**公開画面専用**です。

## サイト

GitHub Pages: https://ri0115.github.io/-ATLAS/

※ GitHubの **Settings → Pages → Build and deployment → Source: GitHub Actions** が設定され、デプロイが成功している必要があります。サイトはそれまでは公開URLで開けません。

- `docs/index.html`：4タブ画面。診療行為データや集計金額は埋め込んでいません
- `docs/assets/style.css`：配色・レイアウト・レスポンシブデザイン
- `docs/assets/app.js`：公開UI操作。詳細APIへの直接接続は行わず、認証付きサイトへ案内
- `docs/assets/public-manifest.json`：**公開を許可した件数などの概要のみ**
- `.github/workflows/pages.yml`：GitHub Pagesへ静的サイトをデプロイ
- `scripts/check_public.py`：公開対象外ファイルや巨大アセットを検出

## データ保護方針

**HTMLにデータを組み込まないだけでは、保護にはなりません。** ブラウザがダウンロードできるCSV/JSONは開発者ツールや直接URLから取得できます。フロントエンドのパスワード、JavaScriptの暗号化、URLの推測しにくさ、CORSだけで秘密データを保護しないでください。

| 項目 | 公開サイト | 保護されたデータ領域 |
|---|---|---|
| 表示コード・スタイル・画面仕様 | ✅ | — |
| 年度、収録コード数、医療圏数などの概要 | ✅ | — |
| 個別コードごとの点数・算定要件の照合記録 | しない | ✅ |
| 医療圏×コード×算定回数・参考換算額 | しない | ✅ |
| 年度内点数改定履歴・監査の生データ | しない | ✅ |
| 全件CSV/SQLite、生成済み大容量HTML | しない | ✅ |

## 認証付き詳細サイト（稼働中）

https://reimbursement-atlas-private.vercel.app/

2024年度のCT・MRI・超音波の収録済み参考換算額を、Vercel Authenticationで保護した別サイトで閲覧できます。2026-11-18更新：全国・47都道府県・330二次医療圏の階層別集計、2地域比較、および上位10件の地域ランキング（技術切替、医療圏の都道府県絞り込み）を実装。集計対象医療圏数を表示し、未収録値はゼロ扱いしません。全国・都道府県の値は収録医療圏の合算であり、完全な診療報酬総額ではありません。

### 人口補正・地域特化指数（2026-11-18追加）

- 人口分母：総務省「住民基本台帳に基づく人口、人口動態及び世帯数調査」2024年1月1日、表24-03（総計、日本人・外国人）。
- 医療圏区分：厚生労働省「令和6年医療施設（動態）調査」二次医療圏・市区町村編 N1、2024年10月1日。
- 結合監査：1,892市区町村・行政区、330医療圏、47都道府県、全地域コード一致。全国総人口124,885,175人、都道府県別人口も原典の47件と一致。名称差1件は竜ヶ崎／竜ケ崎の表記揺れ。
- 人口1人当たり参考換算額＝当該技術の参考換算額／住民人口。
- 全国平均比＝地域の人口1人当たり参考換算額／全国の人口1人当たり参考換算額×100。
- LQ＝当該地域のCT・MRI・超音波3技術の合計に占める当該技術の構成比／全国の同構成比。全診療報酬を分母にしたLQではない。
- 収録済み医療圏の金額が欠落している場合は該当指標を算出しない。収録値にはなお秘匿等による部分集計の限界がある。医療機関所在地別の分析で、住民本人の医療費や年齢調整済み受診率ではない。

出典：[住民基本台帳人口 表24-03](https://www.e-stat.go.jp/stat-search/files?stat_infid=000040306672) / [医療施設調査 N1](https://www.e-stat.go.jp/dbview?sid=0004048437)。

詳細サイトの実データはVercel側の非公開ファイルにあり、この公開リポジトリとは分離されています。公開マニフェストの `details_api_enabled: false` は**GitHub Pagesからの直接API呼び出しが無効**という意味です。

現行サイトはVercelのプロジェクト閲覧権限で保護しています。利用者別の許可地域、個別コード明細、年齢調整、全診療報酬構成比、共通診断料や公費区分の独立集計、レート制限・アクセス監査は未実装です。ランキングAPIは上位10件だけを返し、全件出力機能は提供していません。

### 今後の拡張構成（構想）

```text
[ブラウザ]
  └─ GitHub Pages：公開UI（HTML/CSS/JavaScript／概要情報）
         │ HTTPS + 認証済みリクエスト（将来）
         ▼
[API/BFF：別ホストのサーバー実行環境]
  ├─ ログイン・セッション認証と権限確認
  ├─ 利用者ごとの閲覧可能範囲判定
  ├─ クエリ件数・検索範囲制限とレート制御
  ├─ 過大な再抽出を避ける最小集計結果のみ返却
  └─ 非公開DB／非公開ストレージ：全9,275コード・330医療圏の詳細
```

認証・認可を**API側で行う**こと。認証後に返すデータは閲覧者から取得可能であり、完全なコピー防止はできません。閲覧権限、返す粒度、CSV出力上限、表示する元データの二次利用条件などを設計します。詳細レスポンスには`Cache-Control: private, no-store`を付与し、非公開ストレージの資格情報をブラウザへ渡しません。

#### 現行の認証付き詳細サイトのAPI

| API | 実装済み機能 |
|---|---|
| `GET /v1/prefectures` | 都道府県一覧 |
| `GET /v1/areas?pref=13` | 医療圏一覧 |
| `GET /v1/areas/{code}/summary?scope=include` | 全国（JP）・都道府県（2桁）・医療圏（4桁）の収録済みCT・MRI・超音波集計、収録値の有無・対象医療圏数、人口、人口1人当たり・全国平均比・3技術内LQ |
| `GET /v1/ranking?level=area&pref=JP&metric=CT` | 上位10件の地域ランキング。level=area/prefecture、metric=CT/MRI/US、basis=amount/perCapita/nationalIndex/lq（既定amount） |
| `GET /v1/population/metadata` | 人口出典・地域区分基準日・結合監査 |

詳細APIはVercel側のみで稼働し、公開サイトから直接呼び出しません。

## 公開前の確認

```bash
python3 scripts/check_public.py
node --check docs/assets/app.js
```

**注意:** `.gitignore` やCIでの検査は補助策です。公開リポジトリに秘密ファイルを一度コミットすると、CIが失敗してもGit履歴から取得できる可能性があります。生データをこの公開リポジトリにコピーしないことを原則にしてください。

## 計算上の注意

参考換算額は公開算定回数に点数を掛けて10円換算した分析指標であり、実際の医療機関収益や利益ではありません。NDBの秘匿、DPCの包括、年度内点数改定、地域区分の変更等により誤差が生じ得ます。

**この公開リポジトリはデータ再配布を目的としていません。** サイトに表示できる内容は今後、公開粒度と一次資料の条件を踏まえて段階的に増やします。
